# Data audit report — DengueWatch Nepal

_Generated by `src/audit.py` on 2026-10-07._

## 1. Gate status: **PASS WITH WARNINGS**

**Warnings**
- Reporting-site counts cover only 3/8 usable seasons ([2018, 2024, 2025]; none for 2020-2023, the big outbreak years): rate = raw cases, no per-site normalisation.
- Sentinel network grew from ~49 sites (2016) to 118 (May 2019+) and 134 (2025); pre-2019 case levels are not comparable (2016-2018 annual totals < 200).

**Decisions**
- Dataset A candidates: data/raw/ewars_dengue_weekly_v2.csv, data/raw/ewars_national_weekly.csv. Chosen: `data/raw/ewars_dengue_weekly_v2.csv` (most usable seasons and most non-missing weeks).
- Dataset B candidates: 144 files. Chosen: `data/raw/nasa_power_v2_daily.csv.gz` -- the only one with T2M_MIN/T2M_MAX, all 67 district points, and a start date >= 12 weeks before 2017.
- NASA POWER `-999` markers in chosen weather file: {'T2M': 0, 'T2M_MIN': 0, 'T2M_MAX': 0, 'PRECTOTCORR': 0, 'RH2M': 0} (converted to NaN in build_table.py).
- Sentinel network size (max functional sites stated per year): 2016: 60, 2017: 64, 2018: 69, 2019: 71, 2024: 134, 2025: 134. 2020-2023 bulletins state 'current number of sentinel sites is 118'. The network roughly doubled after May 2019 -- pre-2019 counts are not comparable in level with later years.

## 4. Known data issues — checked
- **2021/2022 parser gap (old CSV):** still present in `data/raw/ewars_national_weekly.csv` -- 2021: 14 weeks, 2022: 28 weeks. Cause: the MonsoonWatch regex needed digits + exact phrasing and missed number-words ('Eight case of dengue was reported'), glued text ('2857cases ofDengue') and the comparison table. Fix: `src/ingest/ewars_dengue_parse.py` (old file untouched; new output `data/raw/ewars_dengue_weekly_v2.csv`). The original URL guesser also only matched late-2025 slugs; `src/ingest/ewars_harvest.py` reads the real links from the 45 index pages instead (+ slug guesses for weeks missing from the index).
- **2025 low season:** 5,823 cases vs 29,149 in 2024. Bulletins are complete for the season, so this is treated as real (immunity / serotype shift). Kept, not dropped.
- **Pre-computed EWARS columns** (`prev_week`, `change`, `last_year`): inconsistent across eras. Not used as features; weekly values recomputed from raw this-week counts. `prev_reported` is used ONLY to recover the value of a week whose own bulletin is missing (logged in Phase 1), after checking it agrees with the direct value elsewhere.
- **`reporting_rate_pct` / district columns:** only 2024-2025 in the old CSV; never used as features.
- **EDCD URL:** all requests use `https://www.edcd.gov.np` (with `www.`).
- **Week alignment:** EDCD weeks are Sunday-ending, numbered from the week ending on the first Sunday on/after 11 Jan. Calibrated per year from bulletin header dates (mode of header_date - 7*(week-1)). Rule matches every calibrated year. 2020 has 53 weeks (its week 53 ended 10 Jan 2021). `src/common/epiweek.py` assumes 52 weeks every year, so it is one week off for 2016-2020; DengueWatch uses `src/epi_calendar.py` instead.
